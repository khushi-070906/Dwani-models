# Dwani-models

Pre-converted NLLB-200 (CTranslate2 format) model bundle for DwaniLive.

This repo hosts only model weights — no source code, no proprietary logic.
Downloaded automatically by DwaniLive's launcher on first run.

## Contents

- `nllb-200-ct2/` — NLLB-200-distilled-600M, converted to CTranslate2 format (int8 quantized)
- `sentencepiece.bpe.model` — the tokenizer file used alongside it

## Source

Converted from `facebook/nllb-200-distilled-600M` on Hugging Face.
